### Introduction

1. Purpose: the user has to control a character and guide it through a level by jumping on platforms and avoiding obstacles, to reach the end of the level.

2. Character controls
    - Menu
        - Arrows to choose character and map
        - Enter key to confirm
        - “esc” return to previous menu
        - “q” to quit application
    - Game
        - "space" to jump or restart level if you died
        - "p" to pause
        - “esc” return to previous menu
        - "q” to quit the application

### System requirements

To play this game, you need
- A computer running Windows, MacOS or Linux
- Racket version 5.3 or later
- An Internet connection (for downloading the software and installing Racket)

### The game

1. Click "Run" in file "main.rkt" and the program will start automatically.
2. Once the game has started, a screen opens where you can choose the character.
3. After selecting the character, choose the level you want to play.
4. Guide the character through the course avoiding obstacles until you reach the end of the level.
5. If the character falls or touches an obstacle the game will display "YOU DIED" and if you press "space" the level restarts from the beginning.
6. If he reaches the end of the level, the game will display "YOU WIN".
7. To exit the level press “esc”.

### Functionality
1. Within the game you can choose between 3 possible characters (blue, red and yellow)
2. You can also choose between 3 possible levels that increase in difficulty
3. The player can jump on blocks, the player rotates when jumping and falling

### Notes
1. The game is inspired by Geometry Dash
